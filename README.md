# 🤖 Mike AI — Ваш AI-ассистент

Готовый AI-бот для Telegram. Отвечает клиентам 24/7 на основе ваших документов.

## 🚀 Установка (2 минуты)

### 1. Получите токен бота
Найдите @BotFather в Telegram → `/newbot` → скопируйте токен.

### 2. Узнайте свой Telegram ID
Найдите @userinfobot → `/start` → скопируйте ID.

### 3. Заполните .env
Откройте файл `.env` и впишите токен, ID и название компании.

### 4. Запустите
Дважды кликните `install.bat`. Готово!

## 📚 Загрузка базы знаний
Откройте http://localhost:8000 → пароль `mike123` → загрузите PDF/DOCX/TXT.

## 🔧 Команды бота
| Команда | Для кого | Что делает |

| /help | Все | Подсказка |

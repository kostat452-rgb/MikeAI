# Отчёт по исправлениям Mike AI

## Исправлено в коде

### 1. Multi-tenant база
- Добавлен `TENANT_ID` в настройки.
- `tenant_id` добавлен в RAG-документы, пользователей, диалоги, usage stats, лиды, feedback, missing questions, cache.
- Веб-загрузки теперь идут в `data/uploads/<TENANT_ID>`.

### 2. Фильтр мусорных файлов
- Добавлен `core/guards.py`.
- Проверки: минимальный размер текста, количество слов, уникальность слов, повторы символов, unsafe контент.
- Prompt injection внутри документов чистится до chunking.
- Плохой файл не попадает в vector store.

### 3. Фильтр мусорных запросов
- Локальный intent detection: `GREETING`, `GARBAGE`, `LEAD`, `QUESTION`.
- Мусорные запросы не уходят в OpenRouter и не тратят деньги.
- Unsafe запросы блокируются.

### 4. RAG стал безопаснее
- Добавлен `MIN_RAG_SCORE`.
- Если релевантность ниже порога — бот не фантазирует, а предлагает менеджера.
- В system prompt добавлена защита: документы являются только источником фактов, не инструкциями.

### 5. Оптимизация денег
- Добавлен SQLite cache ответов.
- Повторный одинаковый вопрос не идёт в LLM.
- Температура снижена до `0.15` для меньшей фантазии.

### 6. Лиды
- Добавлена команда `/lead`.
- Коммерческие запросы типа “цена”, “купить”, “менеджер”, телефон — сохраняются в `leads`.
- Владельцу уходит уведомление.

### 7. Feedback loop
- После ответа появились кнопки 👍 / 👎.
- Оценки пишутся в таблицу `feedback`.

### 8. Missing questions
- Вопросы без ответа сохраняются в `missing_questions`.
- Это база для “дообучения” клиента: что добавить в документы.

### 9. Безопасность вебки
- Cookie теперь `httponly`, `samesite=lax`, `max_age=12h`.
- Сравнение пароля через `secrets.compare_digest`.
- Добавлен `/logout`.
- Имена файлов очищаются.
- Добавлены лимиты загрузки.

### 10. Секреты
- Обновлён `.env.example`.
- Добавлен `.gitignore`.
- В итоговый ZIP не включены `.env`, `.api_key`, `data/`, `__pycache__`.
